# modelos-graficos-probabilisticos

Material del curso de modelos graficos probabilisticos.

## Instalacion local con uv

1. Instala `uv`:
   https://docs.astral.sh/uv/getting-started/installation/

2. Clona el repositorio:

```bash
git clone https://github.com/patymunoz/modelos-graficos-probabilisticos.git
cd modelos-graficos-probabilisticos
```

3. Crea el entorno virtual:

```bash
uv venv .venv --python 3.13
```

4. Activa el entorno:

macOS/Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

5. Instala dependencias:

```bash
uv pip install -r requirements.txt
```
